## 当前设计与代码

- DeepSeek 只输出自然正文，完整短句立即合成；Jev 并行判断倾听表情、回复表情、手势和强度，不阻塞语音。合成开始时固定该句段的声音语气；没有同轮次、同正文判断的新句段使用自然语气，不沿用上一句情绪。
- 统一表现控制器按会话隔离，一个请求执行槽、一个最新待处理槽；实际播放身份放行动作，预判下一句不改当前正在播放的表情。
- 唯一 v2 主题与快照，字幕用 instance/reply/segment 关联；视觉修订不重演动作。打断、换轨、重连、结束和后台恢复使旧动作失效。
- 准备→发力→收回由实际音频驱动，口型独占嘴参数，停止立即闭嘴；身体小幅跟随最终头部姿态，借用同一阻尼与回收，动态计算留在渲染器。
- 桌面全屏舞台＋可收起对话浮层＋底部操作栏；手机当前字幕＋历史抽屉。草稿、历史、焦点、输入法、权限失败、播放受阻及设备切换共用真实组件。
- WSL systemd CPU 子组的各级限额实际均为无限额，宿主亲和性为 32 核。修正原先只接受 CPU 根组导致 SDK 回退 2 核的误判，仍保留过载保护、有限配额和未知容量的保守处理。
- 使用 SDK 公开 conversation_item_added 的 ChatMessage.metrics，记录有限数值，不记录正文或音频；房间 playback_latency 不算浏览器实际出声。
