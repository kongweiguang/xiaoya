# 极简重构分层验收

日期：2026-10-07～09。代码重构与自动化验收已通过；稳定版模型工程和真人设备仍未完成。本记录是公开摘要，原始日志、截图、候选工程和历史失败记录留在本机，不随源码提交。通过代码检查不代表整套方案已经正式交付。

## 已实现

- 唯一 ExpressiveAgent、严格的 `[xiaoya:<style>|<gesture>]` 内部协议；普通括号正文保留，取消不补说、不补演。
- 会话唯一持有 SDK 客户端和表现快照，启动中途失败逐项回收；正常关闭由 Job 生命周期触发。
- 主 Agent 固定 WebSocket Paraformer。PCM／WAV 共用异步准入、首包失败和取消清理；HTTP 转写仅为分帧诊断。
- 单连接 Attempt、共享控制通道、GPU 与 Room 分离、唯一可听音频出口；草稿与历史不因结束或重连清空。
- 令牌仅接受同源浏览器 `POST {}`，服务端决定房间和权限；远程入口必须经已认证网关。
- 三个后端统一由项目 systemd 管理，Agent 仅以公开 `worker_registered` 报告就绪。
- 演示 MCP 独立为示例；退役模式、重复包装和生成 SDK 产物移出当前源码维护。

环境为本机 `http://127.0.0.1:3000/`、Edge 154.0.4258.37、桌面 1440×900／窄屏 390×844。Browser 插件不可用，使用已存在的 Playwright，不额外安装浏览器依赖。

| 检查 | 结果 |
| --- | --- |
| 页面身份 | URL 正确，标题“小芽 · 和你聊聊” |
| 非空页面 | 角色、对话、开始与文字入口正常；待开始时媒体上下文零 |
| 框架错误覆盖层 | 正常流程无覆盖层 |
| Console／页面异常 | 正常主测零；实际信令故障仅两条预期 SDK warning |
| 视觉 | 桌面／窄屏、明暗主题无明显遮挡或横向溢出；减少动态效果为静态角色 |
| 实际交互 | 开始→回复→保留草稿→结束→重连；缩窄恢复、信令中断→恢复→自然回收通过 |

22 个 AudioContext 全部关闭，最终可听音频元素为零，公开房间自然归零。活动期间保持 1 个上下文、1 个可听出口与 1 个画布，13 项角色资源各加载一次。20 个 GC 样本为 27.78～29.13MiB，最终 27.50MiB，在该观察窗口内无持续增长。

同一未发送草稿随桌面→窄屏→桌面调整为 38→58→38px 高度；结束／重连仍保留且不自动发送。真实信令关闭到达浏览器后显示恢复提示、暂时禁用输入，约 2069ms 恢复，历史逐字不变、音频上下文不重建。前两份故障注入脚本断言失败记录保留，第三份实测通过，不以删报告制造通过。
