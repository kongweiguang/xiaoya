# Jev 人物表现与沉浸式交互

小芽使用唯一 `ExpressiveAgent`。DeepSeek 只生成自然口语；Jev 是表情、动作和说话语气的唯一语义来源。没有文本控制头解析、旧协议适配或第二套表现模式。业务工具继续委托原应用用例。

参考 [open-annie](https://github.com/rehan-remade/open-annie) 的语音与人物判断并行、动作置信度门、真实音频发力点和表情保持策略，按小芽的 Live2D 参数实现。请求采用 [OpenRouter Decisions API](https://openrouter.ai/blog/tutorials/how-to-use-jev/)，固定请求模型 `typesafe/jev-1.13`，校验已实测的响应版本 `typesafe/jev-1.13-20260917`。通过独立 HTTP 代理访问，分别验收中文内容与网络耗时。

## 分工与响应

| 职责 | 驱动依据 | 执行边界 |
| --- | --- | --- |
| 自然待机、眨眼、轻微视线 | 生命周期及真实时间 | 无 Key 也正常运行 |
| 倾听与思考表情 | 用户转写和 Jev 判断 | 增量稳定 600ms；倾听仅轻点头／歪头，思考只表情 |
| 回复表情与短手势 | 当前回复正文和 Jev 判断 | 精确片段身份及实际可听音轨 |
| 明确动作、重复与停止 | 完整用户输入的独立 Jev 判断 | 当前轮次及连接所有者，不等待回复或音频；客户端回执闭环 |
| 口型与动作发力点 | 同一个 PCM 分析链路 | 口型独占嘴参数；停止立即闭嘴 |
| 声音语气 | 合成开始前已获得的 Jev 风格 | 不等待 Jev；开始合成后固定本句段声音 |

DeepSeek 普通闲聊优先一句短而完整的实质回应（约 8～16 字），复杂问题先给结论再按需要展开；这是文风偏好，不截断正文或预置回复。完整短句直接进入 SDK 独立播放段落，同时触发并行 Jev 预判。句末立即提交，长句在自然逗号位置切分，保留小数、编号、括号、引号及字幕原文。取消直接丢弃未完成缓冲。Jev 正在判断同一轮次、完全相同的正文时，结果可以绑定当前真实播放身份；其他迟到结果作废。声音只使用同轮次、同正文的已采纳判断，未判定新句段不继承上一句情绪。连续转写只追加时，已持续 600ms 的前缀可提供倾听反应；文本修正撤销旧判断，转思考后旧前缀不再采用。完整命令仍只用最终全文授权。

每次生成只在历史副本加入紧凑的最近完成动作及重复请求约束，不累积到历史。匿名计时分别记录输入完成、默认模型节点首个含正文内容块、首完整语义段、首 TTS 请求与首音频帧，用于区分生成等待、句界等待与合成；首内容块不是原始 HTTP/SSE 首字节或单 token，服务端首音频帧也不是实体扬声器出声。

七种风格：neutral、happy、gentle、concerned、curious、shy、surprised。五种手势：nod、tilt、wave、shy、shake；none 不执行额外手势。Jev 不能生成渲染参数或扩展未注册动作。风格映射到 neutral、happy、gentle 三种同音色声音预设。

## 配置与故障

网页使用同形象的官方分层 `native-v1` 资产包，19 普通参数、0 BlendShape，头、身体、双臂及手掌等共18个独立部件。海报由当前模型中性帧直接导出；根清单、贴图、表情、物理、MotionSync 与后备图作为整体切换。模型验收检查真实可见网格位移，不能把 Core 参数值或动作回执单独当作视觉成功。旧 Concept 包和切换前清单均保留可回退。

在根目录被忽略的 `.env.local` 填入：

```dotenv
VOICE_AGENT_JEV_BASE_URL=https://openrouter.ai
VOICE_AGENT_JEV_MODEL=typesafe/jev-1.13
VOICE_AGENT_JEV_API_KEY=
VOICE_AGENT_JEV_PROXY_URL=http://127.0.0.1:10808
```

Key 空时，角色保持自然待机、微姿态和真实口型，对话正常运行。填 Key 后验证 OpenRouter HTTPS 根地址、固定模型与显式 HTTP 代理。密钥只由 Agent 使用，不进入浏览器、日志或示例。API 使用 `POST /api/alpha/decisions`。`decide_user` 独立判断 requested_gesture、prohibited_gesture、倾听 style／gesture 与 energy；按精确轮次和用户文本共享任务及缓存。`decide` 根据用户原文、当前回复句段和最近一轮已正常播放完成的对话，判断回复 style／gesture／energy，不要求回复自述动作。Choice 分类置信度与 `1 − P(none)` 执行概率分别守 0.85／0.90；表情守 0.65。Score 等级归一化为 0～1。程序负责身份、优先级、冷却、取消与回执，不让模型决定这些确定性规则。

优先级为取消及禁止→明确指令→回复动作→倾听动作→待机微动。“不要摇头”禁止本轮摇头；“别动／停下动作”撤销当前并抑制本轮手势，下轮恢复。指令判断在文字提交或实际语音轮次完成后即可执行，STT final 片段不能替代完整输入。指令一轮执行一次，同轮回复不重复。新输入平滑取消旧动作。重复请求仅引用最近一次收到 completed 回执的指令；没有记录就澄清。首期单动作，复合或未支持请求由口语回复澄清，不能选一个猜着做。

OpenRouter 返回带日期的固定响应模型名；概率与 Score 的两位小数舍入会累计误差，解析器只允许对应维数的舍入预算，仍拒绝越界、非有限值、未知分类或不一致结果。代理不继承系统环境，也不在失败时改为直连。WSL NAT 通过 Windows 启动器管理的专用转发访问现有 `10808` 日本代理，运行地址随当前 WSL 网卡更新，详见 [部署说明](../deployment/README.md)。

每个会话持有一个当前表现判断、当前和下一句两个有界预判槽及独立用户请求判断，复用一个异步连接池。舞台通道就绪后并行免费 HEAD 预热代理 TLS，独立连接任务最多 5 秒。预热失败只影响连接复用优化，不阻止真正的 Decisions 请求，也不计入业务熔断。正式请求直接在原总时窗内使用同一连接池，在实际付费 POST 前再次核对关闭与截止许可；用户请求沿用可以原位升级的同一个截止时钟。当前实际播放优先，取消不匹配当前句的过期判断；匹配当前正文的预判直接晋升，未来句不能挤掉先播句。同轮次精确用户文本共享请求；最终输入可原位延长尚未结束的倾听请求，成功结果不重查，已失败的短判断仅在完整输入边界重新判断一次。新用户轮次和挂断回收旧请求，取消当前判断不反复中断冷连接。用户增量稳定 600ms 后提交；回复按完整短句立即提交，控制器提供 450ms 的非最终更新合并预算。领域统一规定包含握手、读取及解析的总时窗：倾听 1.2 秒、回复 3.5 秒、完整输入 8 秒；应用只额外保留 0.2 秒兜底，语音不等待这些预算。过期输入不能在免费握手迟到后再发付费请求。无效或低分结果不执行动作；倾听短窗正常到期不计入服务熔断。三次连续服务故障后冷却 30 秒；持续限流按 1／2／4 秒指数退避至 30 秒，服务端 Retry-After 更长时优先遵守，成功后重置。无效 Key 本会话停用，诊断脱敏。关闭监督所有会话持有的判断和截止任务，取消连接预热后释放连接池。

网页文字通过公开 `TextInputOptions` 回调接入：验证当前会话和连接所有者，等待旧回复打断完成，再委托与语音相同的轮次方法并生成新回复。等待期间重查关闭与身份，空文字和非所有者不启动模型。SDK 的 `on_user_turn_completed` 不覆盖直接文字生成路径，不能把该钩子当成网页文字已提交的证据。对支持的短动作请求，用完整自然短句回应；正文仍不包含控制头，不声称已观察到动作完成。

## 唯一 v3 控制协议

复用可靠主题 `xiaoya.delivery` 和快照 RPC `xiaoya.getDeliverySnapshot`。全部字段必需：

```text
v=3, instance, revision, reply_id, segment_id, state,
style, gesture, phase, turn_id, gesture_id, gesture_source, command_feedback, energy
```

`phase` 为 idle/listening/thinking/speaking，仅表示语音阶段；`gesture_source` 为 none/dialogue/command。自然说话必须绑定 turn/reply/segment 及真实音频；倾听和指令只要求当前 turn、连接所有者及可见舞台。`gesture_id` 为稳定的一次执行身份，`energy` 为 0～1。字幕按 instance/reply/segment 确认关联，revision 仅判断视觉状态新旧，表情更新不会重演动作。指令跨语音阶段保持同一身份；idle 时有有效指令仍为 active。口型始终独立核对字幕与真实 PCM，指令不能绕过嘴部许可。

动作回执 RPC `xiaoya.ackPresentation` 只有当前已就绪连接所有者可调用。严格携带 `{instance, turn_id, gesture_id, status}`，status 为 started/completed/canceled/unavailable。实际模型成功绘制后才发送开始或完成；completed 必须先有 started，终态幂等且旧身份不能推进新动作。下发 1.5 秒未开始或开始 4 秒未完成，撤销许可并提示结果未知／可重试，不自动重放。只有 completed 写入最近完成指令。`command_feedback` 为 none/retry/clarify，复用状态区与现有发送入口，重试不覆盖草稿。完整输入尚未识别出动作就失败也发送反馈；没有当前实例、当前轮次的已知指令时只提示暂不可用，不显示动作重试按钮、不借用上一轮动作。LLM 只获当前执行事实：未 started 不自述正在做，未 completed 不声称已完成。

字幕输入完成只关闭文字流，播放身份保留至公开 SDK 的实际播放完成；换段和新轮次按精确身份撤销，打断立即撤销。回复完成回调不能关闭后来的回复。服务端播放队列与浏览器媒体缓冲的尾部单独实测，口型仍只跟随当前授权的真实 PCM。

打断、换轨、断线重连、结束、页面隐藏均封存旧身份。重连快照可以恢复微表情，不能补演过去动作。动作采用准备→发力→收回，启动时锁定强度，保留位置与速度平滑衔接；表情至少保持 1.1 秒，句段变化不强制中性。同轮低置信度判断延续最近一次达到 0.65 的 Jev 神态；高置信度的中性判断可以归零，未来句预判不能提前改变当前神态。新输入、整段回复完成和关闭撤销这份缓存，迟到自然判断不能重新激活它；缓存不继承动作或声音。自然动作至少间隔 3 秒、同类 6 秒、任意 10 秒至多两次，指令不受此冷却。倾听幅度约指令 30%，说话自然手势约 45%。语音实际起音只控制发力和次级姿态，不猜测情绪。身体小幅跟随最终头姿，复用现有阻尼与收回，没有第二个动作循环。逐帧更新留在渲染器，React 不承担动画时钟。`RoomAudioRenderer` 保持唯一可听出口，分析器不重复播放或停止 SDK 音轨。

主手势在准备及收回的 120ms 内平滑接管冲突的头部轴：点头 Y、摇头 X、歪头／挥手 Z、害羞 XYZ。相应轴的待机、生命周期和语音微姿态暂时让位，其他轴继续自然运动；取消后同样平滑归还，保留阻尼、Jev 表情叠加和真实 PCM 嘴部独占。动作曲线、强度和验收角度不变，避免轻歪头被负向待机姿态抵消。

私有 TTS 首次输出前以 24kHz PCM16 的 20ms 窗检查持续信号：连续三个窗 RMS 大于 0.004，且每窗至少 48／480 个样本绝对幅值达到 0.002，才放行缓存的原始字节。此门拦截极弱噪声和稀疏尖峰，不调整增益、不删前后停顿、不代替语言可懂度或浏览器口型验收。缓存最多 1MiB；未输出且合成完整失败时，仅按相同文案／预设重试一次，取消或已输出后不重试。浏览器继续独立按原 0.012 能量门驱动口型。正常与拒绝只记录固定模板的 RMS、连续窗数和样本数，不记录正文或音频。

## 界面与资源所有权

桌面为全屏舞台、可收起对话浮层和底部操作栏；手机显示角色、当前字幕及操作栏，历史从底部抽屉展开。开始可选语音或文字，权限失败能继续打字，播放受阻提供启用声音操作，设备切换收在菜单。输入保留草稿，中文输入法不误提交，阅读旧消息不被滚动抢走，抽屉关闭恢复焦点。主题、窄屏软键盘和减少动态效果共用同一真实组件链路。

会话启动成功后才发送开场白；失败逐项回收。Job 负责正常关闭，会话独立持有 SDK、表现任务、快照和工具。浏览器每次连接 Attempt 持有 Room、AudioContext 和取消信号，结束/重连保留历史和草稿。角色 GPU 由页面舞台独立持有。

### 开场输入与回声

会话显式设置公开 `aec_warmup_duration=0.0`。SDK 的默认三秒开场保护不仅禁止语音打断，还把送往 STT 的用户音频替换为静音；小芽保留开场即到达的真实输入，按同一 VAD 规则打断。网页采集继续请求浏览器 echoCancellation，实际扬声器回声消除与自然度需单独做真人设备验收，不能由这个配置或合成麦克风推断通过。

轮次最小等待固定 0.90 秒、最大 1.10 秒，VAD 打断最短持续时间显式固定 0.50 秒。六组私有停顿／噪声网格中，0.60 和 0.75 秒存在提前提交，0.90 秒两组符合声学质量门；两组固定回复 p95 相差不足 1ms，保留 0.50 秒，不以单重复微小差异宣称生产最优。实际输入、识别精度、内存播放与浏览器首声分别记录。

## 模型与验收

官方 Cubism Editor 5.3.04 制作新模型，19 有效普通参数、0 BlendShape，保留小芽身份及参数 ID/范围。先通过闭眼＋笑眼＋视线、闭嘴＋嘴形、挥手＋头身三组样机，再验收七风格×五手势的 35 组合及插值。FREE 保存、实际打开/保存/关闭/重开、兼容导出和浏览器运行全部通过后，源工程、模型、纹理、海报及配置整体晋升。旧候选的往返不能替代新候选验证。

离线 Mock Jev 验证协议、阈值、并发、故障、取消与 257 条固定中文样例的契约；保留原 157 个 ID，另加 100 条自然对话。明确指令与自然表现分别统计，不相互填补覆盖。真实门为精度至少 95%、指令覆盖至少 95%、自然手势覆盖至少 85%、关键误执行零。Mock 不证明真实服务质量，失败报告保留。填 Key 后可显式执行实测：

```powershell
uv run python scripts/evaluate_jev.py --help
uv run python scripts/evaluate_jev.py --mock
# 确认 Key 已填写后，显式付费调用
uv run python scripts/evaluate_jev.py --live
```

语音 p50/p95、Jev p50/p95、真实私有房间、合成麦克风和真人设备分别记录。所有本次结果见 [分层验收记录](delivery-acceptance.md)，历史材料不算本次通过。
