# Jev 人物表现与沉浸式交互

小芽使用唯一 `ExpressiveAgent`。DeepSeek 只生成自然口语；Jev 是表情、动作和说话语气的唯一语义来源。没有文本控制头解析、旧协议适配或第二套表现模式。业务工具继续委托原应用用例。

参考 [open-annie](https://github.com/rehan-remade/open-annie) 的语音与人物判断并行、动作置信度门、真实音频发力点和表情保持策略，按小芽的 Live2D 参数实现。请求与判断原语采用 [TypeSafe 官方 API](https://docs.typesafe.ai/api)，固定 [jev-1.13.0](https://docs.typesafe.ai/models) 后分别验收中文内容与网络耗时。

## 分工与响应

| 职责 | 驱动依据 | 执行边界 |
| --- | --- | --- |
| 自然待机、眨眼、轻微视线 | 生命周期及真实时间 | 无 Key 也正常运行 |
| 倾听与思考表情 | 用户转写和 Jev 判断 | 当前用户轮次；不执行说话手势 |
| 回复表情与短手势 | 当前回复正文和 Jev 判断 | 精确片段身份及实际可听音轨 |
| 口型与动作发力点 | 同一个 PCM 分析链路 | 口型独占嘴参数；停止立即闭嘴 |
| 声音语气 | 合成开始前已获得的 Jev 风格 | 不等待 Jev；开始合成后固定本句段声音 |

DeepSeek 普通闲聊优先一两句短话，复杂问题先给结论再按需要展开。完整短句直接进入 SDK 独立播放段落，同时触发并行 Jev 预判。句末立即提交，长句在自然逗号位置切分，保留小数、编号、括号、引号及字幕原文。取消直接丢弃未完成缓冲。Jev 正在判断同一轮次、完全相同的正文时，结果可以绑定当前真实播放身份；其他迟到结果作废。声音只使用同轮次、同正文的已采纳判断，未判定新句段不继承上一句情绪。

七种风格：neutral、happy、gentle、concerned、curious、shy、surprised。五种手势：nod、tilt、wave、shy、shake；none 不执行额外手势。Jev 不能生成渲染参数或扩展未注册动作。风格映射到 neutral、happy、gentle 三种同音色声音预设。

## 配置与故障

在根目录被忽略的 `.env.local` 填入：

```dotenv
VOICE_AGENT_JEV_BASE_URL=https://api.typesafe.ai
VOICE_AGENT_JEV_MODEL=jev-1.13.0
VOICE_AGENT_JEV_API_KEY=
```

Key 空时，角色保持自然待机、微姿态和真实口型，对话正常运行。填 Key 后验证官方 HTTPS 地址与固定模型。密钥只由 Agent 使用，不进入浏览器、日志或示例。API 使用 `POST /v1/systemone`，每次批量提出 style Choice、gesture Choice、perform Noul、energy Score 四个问题；Score 等级归一化为 0～1，不与 Noul 概率混用。

每个会话只有一个执行中请求和一份最新待处理输入，复用一个异步连接池。用户增量合并 600ms；回复按完整短句立即提交，控制器提供 450ms 的非最终更新合并预算。倾听超时 700ms，回复超时 900ms；语音不等待这两个预算。表情置信度至少 0.65，手势置信度至少 0.85 且执行概率至少 0.90。无效或低分结果不执行动作。三次连续失败后冷却 30 秒；持续限流按 1／2／4 秒指数退避至 30 秒，服务端 Retry-After 更长时优先遵守，成功后重置。无效 Key 本会话停用，诊断脱敏。关闭取消唯一任务后释放连接池。

## 唯一 v2 控制协议

复用可靠主题 `xiaoya.delivery` 和快照 RPC `xiaoya.getDeliverySnapshot`。全部字段必需：

```text
v=2, instance, revision, reply_id, segment_id, state,
style, gesture, phase, turn_id, gesture_id, energy
```

`phase` 为 idle/listening/thinking/speaking。说话状态必须绑定 turn/reply/segment，`gesture_id` 为稳定的一次执行身份，`energy` 为 0～1。字幕按 instance/reply/segment 确认关联，revision 仅判断视觉状态新旧，表情更新不会让字幕失配或重演动作。倾听表情绑定当前轮次，动作另需匹配已授权字幕和当前实际音轨。

字幕输入完成只关闭文字流，播放身份保留至公开 SDK 的实际播放完成；换段和新轮次按精确身份撤销，打断立即撤销。回复完成回调不能关闭后来的回复。服务端播放队列与浏览器媒体缓冲的尾部单独实测，口型仍只跟随当前授权的真实 PCM。

打断、换轨、断线重连、结束、后台恢复均封存旧身份。重连快照可以恢复微表情，不能补演过去动作。动作采用准备→发力→收回，启动时锁定强度，保留位置与速度平滑衔接；相同表情有保持时间，参数按职责合成，嘴部不被表情覆盖。身体以小幅比例跟随最终头部姿态，借用现有阻尼和取消收回，没有第二个动作循环。逐帧更新留在渲染器，React 不承担动画时钟。`RoomAudioRenderer` 保持唯一可听出口，分析器不重复播放或停止 SDK 音轨。

## 界面与资源所有权

桌面为全屏舞台、可收起对话浮层和底部操作栏；手机显示角色、当前字幕及操作栏，历史从底部抽屉展开。开始可选语音或文字，权限失败能继续打字，播放受阻提供启用声音操作，设备切换收在菜单。输入保留草稿，中文输入法不误提交，阅读旧消息不被滚动抢走，抽屉关闭恢复焦点。主题、窄屏软键盘和减少动态效果共用同一真实组件链路。

会话启动成功后才发送开场白；失败逐项回收。Job 负责正常关闭，会话独立持有 SDK、表现任务、快照和工具。浏览器每次连接 Attempt 持有 Room、AudioContext 和取消信号，结束/重连保留历史和草稿。角色 GPU 由页面舞台独立持有。

### 开场输入与回声

会话显式设置公开 `aec_warmup_duration=0.0`。SDK 的默认三秒开场保护不仅禁止语音打断，还把送往 STT 的用户音频替换为静音；小芽保留开场即到达的真实输入，按同一 VAD 规则打断。网页采集继续请求浏览器 echoCancellation，实际扬声器回声消除与自然度需单独做真人设备验收，不能由这个配置或合成麦克风推断通过。

轮次最小等待固定 0.90 秒、最大 1.10 秒，VAD 打断最短持续时间显式固定 0.50 秒。六组私有停顿／噪声网格中，0.60 和 0.75 秒存在提前提交，0.90 秒两组符合声学质量门；两组固定回复 p95 相差不足 1ms，保留 0.50 秒，不以单重复微小差异宣称生产最优。实际输入、识别精度、内存播放与浏览器首声分别记录。

## 模型与验收

官方 Cubism Editor 5.3.04 制作新模型，19 有效普通参数、0 BlendShape，保留小芽身份及参数 ID/范围。先通过闭眼＋笑眼＋视线、闭嘴＋嘴形、挥手＋头身三组样机，再验收七风格×五手势的 35 组合及插值。FREE 保存、实际打开/保存/关闭/重开、兼容导出和浏览器运行全部通过后，源工程、模型、纹理、海报及配置整体晋升。旧候选的往返不能替代新候选验证。

离线 Mock Jev 验证协议、阈值、并发、故障、取消与 138 条固定中文样例的契约；这不证明真实云模型的中文准确率或网络延迟。填 Key 后可显式执行实测：

```powershell
uv run python scripts/evaluate_jev.py --help
uv run python scripts/evaluate_jev.py --mock
# 确认 Key 已填写后，显式付费调用
uv run python scripts/evaluate_jev.py --live
```

语音 p50/p95、Jev p50/p95、真实私有房间、合成麦克风和真人设备分别记录。所有本次结果见 [分层验收记录](delivery-acceptance.md)，历史材料不算本次通过。
